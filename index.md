## One public source of truth

Content merged into the production documentation branch and published on this domain is the canonical public documentation for WEDNESDAY. Technical claims should be traceable to production behavior, a production specification, or an explicitly versioned public contract.

<div class="notice"><strong>No invented capabilities.</strong> Model limits, API endpoints, tool behavior, quotas, and lifecycle claims are published only after they are verified against the production system.</div>

## Machine-readable by design

The same documentation is intended for people, search engines, and AI agents. Start with [`/llms.txt`](/llms.txt) for the routing index or [`/llms-full.txt`](/llms-full.txt) for the consolidated public corpus available today.
