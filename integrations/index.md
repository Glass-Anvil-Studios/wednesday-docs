# Integrations

<p class="lead">Integration pages describe supported third-party connections, permissions, data boundaries, and user-visible behavior.</p>

## Integration entries

A complete entry should identify the provider, supported actions, authorization model, data accessed, data modified, known availability constraints, and revocation path where applicable.

## Third-party boundaries

Third-party service behavior, pricing, limits, and availability may change independently of WEDNESDAY. Public documentation should make those boundaries explicit rather than presenting external behavior as a WEDNESDAY guarantee.
