# Models

<p class="lead">This section will contain the public, production-verified WEDNESDAY model catalog.</p>

## Publication standard

A model entry is published only when its identifier and user-relevant behavior have been verified against the production platform. Each entry should document only what is safe to treat as a public contract, including supported modalities, relevant limits, tool compatibility, lifecycle state, and migration guidance where applicable.

<div class="notice"><strong>Catalog status:</strong> no detailed model specification has been published in this repository yet. Do not infer model limits or capabilities from UI labels or internal roadmap material.</div>

## Planned reference fields

| Field | Purpose |
| --- | --- |
| Model ID | Stable public identifier used by supported interfaces |
| Modalities | Published input and output modalities |
| Tool support | Verified compatibility with documented tools |
| Limits | Public context or request limits when applicable |
| Lifecycle | Current, preview, deprecated, or retired |
| Updated | Date the public specification was last verified |
